# 랭킹 릴스 만드는 법 (계정 myeotwi.ya · 몇위야)

매일 예약 실행 세션이 이 순서대로 한다. 10:30 KST 에 시작해 10:55 게시 시각으로 대기열에 넣는다(10:59 에 다른 예약 작업이 게시 워크플로우를 돌려 11:00 무렵 올라감). 사람에게 묻지 않는다(묻지 말고 가장 그럴듯한 쪽으로 정하고, 정한 것을 결과 보고에 적는다).

근거: 조사 결과(INSTA `주제/랭킹/조사_랭킹계정_20261030.md`) — 순위 이미지 1장을 8초 릴스로 올린 계정(tap.pick, 팔로워 1,955명)이 10만~400만 조회.

## 1. 소재 고르기
1. 이 폴더 `사용소재.md` 를 먼저 읽는다. 표의 `피함 끝` 날짜가 지나지 않은 소재(같은 분야 · 같은 달 자료)는 고르지 않는다.
2. 조건(모두 맞아야 함)
   - 순위 10~15개를 **공개 자료 원문 또는 기사로 확인**할 수 있다. 자료에 없는 순위를 지어내거나 추정해 채우지 않는다.
   - 보는 사람이 **자기 자리를 찾을 수 있는** 대상이다(브랜드 · 동네 · 학교 · 직업 · 앱 · 음식 · 아이돌 · 성씨 등). "우리 ○○는 몇 위?" 로 물을 수 있어야 한다.
   - 최근 자료다(발표 30일 이내 우선). 날짜 · 기간을 이미지와 캡션에 쓴다.
3. 소재 찾는 곳(우선순위)
   - 한국기업평판연구소 월간 브랜드평판(분야가 수십 개라 매일 다른 분야를 쓸 수 있다). 검색어 예: "2026년 11월 ○○ 브랜드평판 순위". 기사(위키트리 · 뉴스1 등)에 1위부터 순서가 실린 것을 쓴다
   - 정부 · 공공 통계(KOSIS, 부동산원, 통계청 보도자료), 조사기관 보고서(오픈서베이 등), 와이즈앱 · 리테일 앱 순위
   - 사람 실명 순위(연예인 개인 등)는 쓰지 않는다(사진도 쓰지 않음)
4. 가능하면 출처를 2곳에서 대조한다. 1곳뿐이면 결과 보고에 "1곳 확인" 이라고 적는다.

## 2. 자료 JSON (figma_fill.js 에 넣는 값)
```json
{
 "slug": "20261031_치킨브랜드평판",
 "badge": "2026년 10월 브랜드평판",
 "title": "치킨 브랜드 순위",
 "stat": "28개 브랜드 · 빅데이터 1,128만 개 분석",
 "hint": "BBQ · 교촌치킨을 제치고\n1위에 오른 브랜드는?",
 "items": ["1위 이름", "2위", "…", "10~15위"],
 "source": "출처: … (기간)\n지표 뜻 한 줄(예: 온라인 언급 · 반응량 지표이며 맛 · 매출 순위가 아님)"
}
```
- `items[0]` 이 1위다. 이미지에는 1위를 "?" 로 가리고 2위부터 보인다. 개수 = TOP N(10~15)
- `title` 은 짧게(한 줄, 12자 안팎). 길면 스크립트가 글자를 줄인다
- `hint` 는 2줄, 사실만(예: "2 · 3위를 제치고 1위에 오른 ○○는?"). 확인 안 된 "또 1위" · "N달 연속" 은 쓰지 않는다
- `stat` 은 자료에 있는 수치만. 없으면 조사 대상 · 기간 한 줄

## 3. 이미지 → 영상 → 대기열
1. Figma 파일 `ZlpoXgGENTfB1ZQekTSFEQ`(INSTA 랭킹) 에서 Figma 도구 `create_session` 다음 `use_figma` 로 `figma_fill.js` 를 실행한다. 셋째 줄 `__DATA__` 를 2절 JSON 으로 바꿔 넘긴다. 돌려받은 frameId 로 `get_screenshot`(maxDimension 1920) → PNG 내려받기(1080×1920 인지 확인)
2. PNG 를 직접 열어 본다: 글자 겹침 · 잘림 · 순위 누락이 없어야 한다. 있으면 자료(글 길이)를 고쳐 다시 그린다
3. 캡션(아래 4절)을 `캡션.txt` 로 쓴다
4. `bash ranking/make_reel.sh <PNG> <캡션.txt> /tmp/pub/<slug>`
5. `python3 enqueue.py /tmp/pub/<slug> myeotwi.ya <오늘>T10:55:00+09:00 --reel /tmp/pub/<slug>/릴스/1판` (릴스 + 같은 영상 스토리가 들어감)
6. 대기열에 넣은 시각이 10:59 를 넘었으면 바로 `gh api -X POST repos/leegyan/insta-publisher/actions/workflows/publish.yml/dispatches -f ref=main` 으로 게시를 돌린다(gh workflow run 은 이 환경에서 GraphQL 이 막혀 실패)
7. `사용소재.md` 표에 한 줄 더하고 main 에 커밋 · 푸시한다(글만. 이미지는 main 에 넣지 않는다)

## 4. 캡션 형식
```
<제목> TOP<N> <이모지 1개>
<힌트 질문 한 줄>...?

.
.
.

두구두구두구 🥁

바로 <1위> 👑
<1위에 대한 자료 속 사실 1~2줄>

너의 최애 <대상>은 몇 위야? 댓글로 알려줘 👇

*<출처 · 기간 · 조사 규모>. <지표 뜻 · 한계>

#해시태그 5개
```
- 해시태그는 5개(인스타그램 최대치), 모두 사람들이 검색할 낱말로 채운다. 계정 이름 태그는 넣지 않는다
- 순서 고정: ① 대상(#치킨) ② 대상+순위(#치킨순위) ③ 달+브랜드평판(#10월브랜드평판) ④ 1위 이름+추천(#BHC추천) ⑤ 대상+추천(#치킨추천)
- 자료가 브랜드평판이 아닐 때만 ③ 은 달+자료 이름(예: #10월앱순위)으로 쓴다(자료와 다른 태그를 달지 않기 위함)
- 내용과 맞지 않는 말(예: 맛집 내용이 아닌데 #치킨맛집)은 쓰지 않는다
- 근거: 조회수 상위 랭킹 릴스(tap.pick · narabi_index)의 해시태그 형식(INSTA 주제/랭킹/조사_랭킹계정_20261030.md)
